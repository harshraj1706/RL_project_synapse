# SYNAPSE ARENA — Reinforcement Learning Racing Agent

Autonomous Reinforcement Learning Racing Agent for **SYNAPSE ARENA**, organized by **VECTOR × AIC** at **IIIT Bhagalpur, India**.

This project implements a clean, modular RL engineering pipeline built for training, evaluation, and zero-shot generalization to unseen racing tracks under strict training step budgets.

## 2. Quickstart & Setup (Windows / PowerShell)

### Prerequisites
- Python 3.11 (Recommended for PyTorch & Gymnasium wheel stability)
- Git

### Installation

1. **Clone & Navigate:**
   ```powershell
   cd d:\synapse
   ```

2. **Create & Activate Virtual Environment:**
   Using `uv` (recommended):
   ```powershell
   uv venv --python 3.11
   .venv\Scripts\activate
   ```
   Or using standard Python 3.11:
   ```powershell
   py -3.11 -m venv .venv
   .venv\Scripts\activate
   ```

3. **Install Dependencies in Editable Mode:**
   ```powershell
   uv pip install -r requirements.txt -e .
   ```
   Or with standard pip:
   ```powershell
   pip install -r requirements.txt -e .
   ```

## 3. Running Tests & Smoke Tests

### Run Unit & Integration Tests
```powershell
pytest -v
```

### Run Synthetic Pipeline Smoke Test (Micro Training)
This verifies configuration loading, environment initialization, PPO training (64 steps), checkpoint saving, and policy reload:
```powershell
python scripts/train.py --config configs/default.yaml
```

### Run Deterministic Evaluation
Evaluate the checkpoint generated by the smoke test:
```powershell
python scripts/evaluate.py --config configs/default.yaml --checkpoint checkpoints/smoke_test/model.zip --episodes 2
```

## 4. Architecture Overview

```text
synapse/
├── configs/                  # Experiment configurations (YAML)
│   └── default.yaml          # Safe default configuration
├── docs/                     # Environment contracts and integration docs
│   └── ENVIRONMENT_CONTRACT.md
├── scripts/                  # CLI execution scripts
│   ├── train.py              # Training entry point
│   └── evaluate.py           # Evaluation entry point
├── src/synapse_arena/        # Core package
│   ├── config/               # Dataclass schema & YAML validation
│   ├── envs/                 # Base interface, official adapter, synthetic test env
│   ├── rewards/              # Reward shaping hooks
│   ├── training/             # Training loop & callbacks
│   ├── evaluation/           # Evaluation runner & metric aggregation
│   └── utils/                # Seed management and logging
└── tests/                    # Automated pytest suite
```

## 5. Important Rules
- **No fabricated metrics:** Results from `SyntheticSmokeTestRacingEnv` verify software plumbing only, never racing capability.
- **Budget conservation:** Never run full training runs or consume training steps during local integration checks.
- **Official simulator:** Will be integrated into `src/synapse_arena/envs/official_adapter.py` once released by organizers.
